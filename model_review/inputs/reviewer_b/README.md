# Reviewer B input package

This folder preserves the seven files supplied for Reviewer B's completed 120-case review. This README was added for public navigation and was not part of the original package.

Read `INSTRUCTIONS.md` for the normative rubric, `POLICY.json` for its settings, and `ACTION_SCHEMA.json` for the action contract. `CASES.json` contains all case records, the trusted approval registry and approval-binding attestations. `PASTE_PROMPT.txt` and `RUN_METADATA.md` show the original request and metadata discipline. `OUTPUT_SCHEMA.json` defines the required response format.

The policy asks whether an action is permitted under stated rules, not whether a claimed incident is true or a mitigation will succeed. Thresholds are illustrative operator choices. Decisions refer to the supplied fixed evaluation time, not the current date.

The intended selection was Gemini 3.1 Pro Extended; the author reported Gemini Pro Extended. The returned metadata could not observe the displayed model or mode, and a separate run-notes file was not supplied. See [the unchanged response](../../responses/README.md) and [the result interpretation](../../../results/08_model_review/INTERPRETATION.md).

The historical prompts are evidence; reading this folder does not authorize network calls, policy execution or a new review. The post-review crosswalk and expected answers were deliberately kept outside this folder.
