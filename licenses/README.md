# Licensing and attribution

We keep ownership and reuse terms visible so that readers can reproduce the work responsibly. Software, our explanatory material and third-party data have separate terms. This folder gathers the supporting notices without changing those terms.

## Which file should I read?

| File | Purpose |
|---|---|
| [LICENSES.md](LICENSES.md) | The overview of which terms apply to each part of the package and the distribution boundaries |
| [REUSE.md](REUSE.md) | Practical guidance for reusing our software, guides and author-owned measurements with attribution |
| [NOTICE.md](NOTICE.md) | Maintainer attribution and the scope of this release |
| [LICENSE-INITIAL-MIT.txt](LICENSE-INITIAL-MIT.txt) | The preserved MIT notice for the initial GitHub template, not a replacement licence for the experimental code |

The complete [Apache-2.0 software licence](../LICENSE) remains at the repository root so that GitHub and readers can find it easily. Our original guides and author-owned results have the rights-limited CC BY 4.0 grant described in [REUSE.md](REUSE.md). Third-party dataset terms remain separate.

## If you use the datasets or evidence archives

Read [the third-party notices](../data/THIRD_PARTY_NOTICES.md) and [dataset acquisition guidance](../data/README.md). The notices identify NetsLab-5GORAN-IDD and 5G-NIDD, their creators, original sources, declared licences and the transformations represented in our evidence. Keep the accompanying README and relevant notices with any dataset-derived material you redistribute.

Original model responses are identified research records, not a blanket grant of provider or third-party rights. See [the review provenance](../model_review/README.md). The withheld manuscript, publication figures and direct paper tables are outside this package's reuse grant.

Documented licences and attribution provide a basis for responsible reuse, not a guarantee of legal clearance or institutional authorization. Consult the detailed terms above and [safe-use guidance](../.github/SECURITY.md) before conducting experiments. Citation metadata is in [CITATION.cff](../CITATION.cff); the paper remains under review.

Return to [the main README](../README.md) to choose a reading or reproduction route.
