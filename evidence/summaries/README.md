# Saved summaries

Start with the [step-by-step results](../../results/README.md). These JSON files retain the more detailed evidence behind those tables. `windows_comparison.json` keeps Workstation 1 and Workstation 2 measurements separate under their unchanged historical identifiers; `packet_recomputation.json` records the independent audit of all 72 episodes; `selected_results.json` records the selected summary metrics used in our evidence assessment. The status/scope files preserve the distinction between the completed initial PoC and deferred confirmatory study.

Numbers here are recorded outcomes, not predictions. Timing boundaries and denominators matter: microseconds of local action processing are not packet response times; load is action proposals per second, not packets per second.
