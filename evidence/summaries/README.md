# Saved summaries

Start with the step-by-step tables in the repository `results` folder. These JSON files retain the more detailed evidence behind those tables. `windows_comparison.json` keeps university and workstation measurements separate; `packet_recomputation.json` records the independent audit of all 72 episodes; `selected_results.json` supports the concise manuscript draft. The status/scope files preserve the distinction between the completed initial PoC and deferred confirmatory study.

Numbers here are recorded outcomes, not predictions. Timing boundaries and denominators matter: microseconds of local action processing are not packet response times; load is action proposals per second, not packets per second.
