# Scientific code

Two clearly separated source families preserve the experiment history. `windows_frozen` contains the frozen Stages 0–5 implementation; `packet_v7` contains the repaired, successfully exercised packet implementation for Stages 6–7. They are not interchangeable versions of a single new experiment.

Use the root reproduction guide and preparation tool to run from a clean canonical snapshot. Browsable trees add explanatory README overlays; original scientific source, tests and settings are preserved.
