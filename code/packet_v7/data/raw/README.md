# Raw data directory

Place the NetsLab-5GORAN-IDD archive or extracted dataset here. Raw files are
ignored by Git and are not committed because of their size and data-minimization
requirements. The official Kaggle data card lists the dataset as CC BY 4.0.

https://netslab.ucd.ie/netslab-datasets/netslab-5goran-idd/

Dataset DOI:
https://doi.org/10.34740/kaggle/ds/7416931

licence details.
