## Included transformation

`data/processed/netslab_contexts_v0.1.json` is an adapted, de-identified
aggregate generated by `scripts/prepare_netslab_contexts.py`. The transformation:

1. verifies the extracted database SHA-256 and SQLite integrity;
2. verifies the required schema;
3. aggregates every `attack_subcategory` stratum using all rows;
4. emits row counts, distinct-identifier counts, and selected signal means;
5. marks six replay contexts, including a benign negative control; and
6. omits raw records, timestamps, UE identifiers, RNTIs, and cell identifiers.

No exact TCP-flood class is substituted, and the generic port-scan class is not
described as UDP. These are intentional changes from the narrower legacy
scenario names. The raw archive and database are not included in this repository.

- Dataset licence: CC BY 4.0, verified against original Fairdata dataset metadata
  on 2026-09-22, not inferred from the paper's licence.

Attribution: Yushan Siriwardhana, Sehan Samarakoon, Pawani Porambage,
Madhusanka Liyanage, Sang-Yoon Chang, Jinoh Kim, Jonghyun Kim and Mika Ylianttila.
Source metadata and a sanitized acquisition receipt remain beside the local raw
archive. Temporary download tokens are never retained. Original records are not

Published archive SHA-256:
`07531b251f3f35be70bf1d3dcca2e27274bd1b267c5a057c0fcea18668b9293d`.
The archive contains one `Combined.csv`; no packet captures or attack scripts
are required. Derived exports identify the selection and transformations, retain
only duration/packet-count summaries for selected records and linkable opaque
source-row references, and separate all simulated control-plane context.

5G-NIDD was collected on a 5G test network, not an O-RAN deployment. It does not
provide safe-action, approval, UE-to-control identity or post-mitigation labels.
The combined processed CSV does not establish independent session boundaries.
